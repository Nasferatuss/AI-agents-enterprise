# Onboarding Process Specification (sample)

When a new employee joins, HR creates a record in the HR system. The IT team then
provisions a laptop and creates accounts in the identity provider. The employee
receives a welcome email with shared credentials for the team wiki.

The manager approves access to the production database. However, an earlier
section states that contractors may never access production. It is unclear who
approves access when the new hire is a contractor.

The system stores the employee's SSN 123-45-6789 and personal email
jane.doe@example.com in the onboarding record. Encryption may be disabled for the
staging environment to speed up testing.

Finance must set up payroll within 3 days. There is no statement about data
retention for terminated employees.
